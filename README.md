# FunCode KOBE 授業タイマー

FunCode KOBEの授業の時程に合わせた、ブラウザーで動くタイマーです。

## 時程

1. もくもくタイム（30分）
2. 休憩（5分）
3. なるほどタイム（25分）
4. 休憩（5分）
5. もくもくタイム（授業時間の残り）

授業時間は85分が初期設定です。プリセットまたは「その他」から66〜240分の範囲で変更でき、授業中も経過時間を保ったまま変更できます。スタート、一時停止、再開、リセットに加えて、「前のタイム」「次のタイム」や時程カードから各タイムへ移動できます。円形ダイヤルのハンドルをドラッグすると現在のタイム内の時刻を、授業の進み具合バーのハンドルをドラッグすると授業全体の中の現在時刻を変更できます。各タイムの終了時に鳴る効果音は3種類から選べ、消音や全画面表示にも対応しています。

## ローカルでの確認

`index.html` をブラウザーで開くか、静的ファイルサーバーでこのディレクトリを配信してください。

## Vercelへのデプロイ

このリポジトリをVercelにインポートし、Framework Presetを「Other」、Build Commandを空欄、Output Directoryを `.` にしてデプロイしてください。
